# Shadow: páginas legales

Pages y son las URL que declara la ficha de la App Store, así que **los nombres
de fichero no se cambian**.

- `privacy-policy.html` / `privacy-policy-es.html`
- `support.html`

El texto vive en el repo de la app (`docs/`); aquí solo está la copia publicada.
